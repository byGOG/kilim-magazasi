# Dokuma storefront

Türkiye odaklı modern halı mağazası için başlangıç arayüzü. Geçici proje adı `Dokuma`dır; marka tescili, alan adı ve marka kararı verilmiş değildir.

## Yerel geliştirme

- `npm install`
- `npm run dev`
- `npm run build`

## İlk kapsam

- Duyarlı ana sayfa, koleksiyon/ürün kartları, beden seçimi, favori ve örnek sepet etkileşimi.
- Hazır ölçü varyantları ile özel ölçü teklif akışı.
- Anadolu dokuma kültüründen ilham alan modern görsel yön.
- Yönetim, gerçek ödeme, kargo, stok, muhasebe ve pazaryeri servisleri henüz bağlanmadı. Üretime geçişte sağlayıcı ve ticari hesap bilgileri gerekir.

## GitHub başlangıcı

1. GitHub'da `kilim-magazasi` gibi markadan bağımsız, geçici ve herkese açık olmayan bir repo oluşturun.
2. Bu klasörü yeni repoya bağlayıp `main` dalına gönderin.
3. Marka ve alan adı netleşince repo adını değiştirmek mümkündür.
4. Önizleme için GitHub deposunu Vercel veya Netlify ile bağlayın; `npm run build` derleme adımıdır.

GitHub hesabı byGOG bağlantısı doğrulandı. Hesapta kilim-magazasi adlı depo yok. Bu oturumdaki GitHub bağlantısı depo oluşturma yetkisi sunmuyor; yerel başlangıç hazır, GitHub’da byGOG/kilim-magazasi adıyla boş ve private repo açıp main dalına push edin.
