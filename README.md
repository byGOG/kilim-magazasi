# Dokuma storefront

Türkiye odaklı online halı mağazası için başlangıç projesi.

- Anadolu dokuma kültüründen ilham alan duyarlı vitrin
- Hazır ölçü seçenekleri ve özel ölçü teklif akışı
- Günlük mağazaya eklenecek 10 ürün hedefi
- Entegrasyon ve ürün planı: `docs/PRODUCT-PLAN.md`

## Yerel geliştirme

- `npm install`
- `npm run dev`
- `npm run build`

Marka adı Dokuma şimdilik prototipte kullanılan geçici addır. Gerçek ödeme, kargo, stok, muhasebe ve pazaryeri bağlantıları henüz eklenmedi.
